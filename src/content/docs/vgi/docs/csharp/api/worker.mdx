## <span class="api-icon api-icon--class"></span><span class="api-kind-tag api-kind-tag--class">class</span> `Worker`

<a class="api-source" href="https://github.com/Query-farm/vgi-csharp/blob/main/src/QueryFarm.Vgi/Worker.cs#L25" target="_blank" rel="noopener">source</a>

<pre class="api-sig"><code>public sealed class Worker</code></pre>

<p class="api-section">Description</p>

<p>Fluent builder for a VGI worker process — ports vgi-java&#39;s Worker builder pattern. Serves over stdio (the default, and what DuckDB&#39;s bare-command LOCATION subprocess transport uses) or over an AF_UNIX socket (RunUnixSocketAsync, the LOCATION &#39;launch:&lt;argv&gt;&#39; pooled-launcher transport). RunTcp / RunHttp and the rest of RunFromArgs &#39;s flag surface land in later milestones. CRITICAL: stdout is the wire channel (stdio mode) or the launcher&#39;s discovery-line channel (unix-socket mode) — never write to Console.Out from a registered function or from a worker&#39;s own Main ; use Console.Error for any diagnostics.</p>

<div class="api-member">

<pre class="api-sig"><code>public async Task RunUnixSocketAsync(string path, double idleTimeoutSeconds = 300, CancellationToken cancellationToken = default) ;</code></pre>
<p>Serves over an AF_UNIX domain socket at path — the launcher transport ( LOCATION &#39;launch:&lt;argv&gt;&#39; ), letting a single worker process amortize its own startup cost across every DuckDB connection/process pointed at the same worker tuple. Follows the worker-side contract in ~/Development/vgi/docs/launcher-protocol.md exactly: binds, emits exactly one UNIX:&lt;abs path&gt; line on stdout (flushed, and nothing else on stdout ever again — logging MUST go to Console.Error), serves each connection on its own task, and self-shuts-down once idleTimeoutSeconds have elapsed with zero connected clients (0 = never times out). Returns once the socket has been closed and every in-flight connection has drained — whether from an idle timeout or cancellationToken being cancelled by the caller (e.g. on SIGTERM/SIGINT).</p>

</div>

<div class="api-member">

<pre class="api-sig"><code>public const string DefaultProtocolVersion = &quot;1.4.0&quot;;</code></pre>
<p>VGI application protocol surface version this worker declares — emitted as the vgi_rpc.protocol_version per-request metadata key and enforced by QueryFarm.VgiRpc.Server.RpcServer (exact major+minor match; patch ignored) at the dispatch boundary, before any method-specific handling runs. Mirrors vgi-python&#39;s VgiProtocol.protocol_version /vgi-java&#39;s Worker.VGI_PROTOCOL_VERSION — bump rules: MAJOR = backward-incompatible surface change, MINOR = additive, PATCH = worker bug fixes. 1.1.0 added the nullable schema_name field to the bind request. 1.3.0 added global_functions / global_function_prefix to the catalog_attach result (see Protocol.CatalogAttachResult). 1.4.0 added table_function_plan (split-based scan planning) plus split_tokens / row_limit on the init request.</p>
