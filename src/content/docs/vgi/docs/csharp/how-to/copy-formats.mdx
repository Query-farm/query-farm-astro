---
title: Add a custom COPY format
description: Register C# table and buffering functions as DuckDB COPY FROM and COPY TO handlers.
---

import CodeBlock from '../../../../../../components/ui/CodeBlock.astro';

A custom reader is an `ITableFunction`; a custom writer is an `ITableBufferingFunction` because it
must sink the input before its source phase completes.

<CodeBlock code={`worker
    .RegisterCopyFromFormat(new LinesReader(), "demo_lines")
    .RegisterCopyToFormat(new LinesWriter(), "demo_lines");`} lang="csharp" tryable={false} />

The framework registers each handler as a normal function and publishes the format metadata.
`TableBindParams.CopyFrom` / `TableInitParams.CopyFrom` carry the source path and required schema;
the buffering bind, process, and combine params carry the COPY TO destination context.

<CodeBlock code={`COPY target FROM 'input.demo' (FORMAT 'demo.demo_lines');
COPY (SELECT * FROM target) TO 'output.demo' (FORMAT 'demo.demo_lines');`} lang="sql" tryable={false} />

Declare format options in the handler's `ArgumentsSchema`. Set `SinkOrderDependent` only when the
output format needs source row order; doing so disables parallel sink ingest.
