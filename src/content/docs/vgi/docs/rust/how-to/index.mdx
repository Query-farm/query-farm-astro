Focused guides that each walk through one task end to end. Each assumes you've finished the
[tutorial](/vgi/docs/rust/tutorial/scalar/) and can already build and run a worker.

Not sure which function shape you need? Start with
**[Function patterns](/vgi/docs/rust/how-to/function-patterns/)** — a runnable worker for each of the
five shapes — then come back here for specific tasks.

## Guides

- **[Function patterns](/vgi/docs/rust/how-to/function-patterns/)** — scalar, table, table-in-out,
  aggregate and buffering, with a complete worker for each. *(Start here.)*
- **[Transports & runtimes](/vgi/docs/rust/how-to/transports/)** — stdio, Unix socket, TCP and HTTP,
  plus the `wasm32` target that runs the worker inside the browser next to DuckDB-WASM.
- **[Expose a catalog](/vgi/docs/rust/how-to/catalogs/)** — present the worker as a database:
  schemas, function-backed tables, views.
- **[Cache results on the client](/vgi/docs/rust/how-to/result-caching/)** — advertise TTLs and
  validators so repeat queries skip the worker entirely.
- **[Report errors well](/vgi/docs/rust/how-to/errors/)** — the `RpcError` constructors, the
  constraints you get for free, and why a `panic!` costs you the whole worker.
