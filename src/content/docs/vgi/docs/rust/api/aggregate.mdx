## <span class="api-icon api-icon--class"></span><span class="api-kind-tag api-kind-tag--class">struct</span> `WindowPartition`

<a class="api-source" href="https://github.com/Query-farm/vgi-rust/blob/main/vgi-client/src/aggregate.rs#L309" target="_blank" rel="noopener">source</a>

<Code lang="rust" code={`pub struct WindowPartition {
    execution_id: Bytes,
    partition_id: i64,
    function_name: String,
    schema_name: Option<String>,
}`} />

<p class="api-section">Description</p>

A window partition cached on the worker.

Window evaluation is two-phase: the whole partition is shipped once, then
each output row's frames are evaluated against it. Dropping this releases
nothing by itself — call [`VgiClient::window_destroy`], which the worker
needs to free the cached partition.
