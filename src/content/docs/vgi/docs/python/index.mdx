**vgi-python** implements the Vector Gateway Interface (VGI) for Python: you write a small worker
exposing typed functions, and DuckDB calls them as if they were native. Data moves as Apache Arrow
record batches, so it stays columnar and fast across the boundary — no row-by-row marshalling.

## Function shapes

VGI workers expose five function shapes — pick the one whose input/output cardinality matches your
problem. Each links to a complete, runnable example in the [function patterns
guide](/vgi/docs/python/how-to/function-patterns/).
