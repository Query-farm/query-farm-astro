<p class="api-module-doc__label">Module overview</p>

Filter pushdown AST classes for table functions.

This module provides:
- Filter AST classes for representing pushdown filter predicates
- [`ColumnBounds`](/vgi/docs/python/api/vgi-table_filter_pushdown/#vgi.table_filter_pushdown.ColumnBounds) for extracting numeric bounds from filters
- [`PushdownFilters`](/vgi/docs/python/api/vgi-table_filter_pushdown/#vgi.table_filter_pushdown.PushdownFilters) container with evaluation and helper methods
- Deserialization from Arrow IPC format



**Filter types**

[`ConstantFilter`](/vgi/docs/python/api/vgi-table_filter_pushdown/#vgi.table_filter_pushdown.ConstantFilter): Comparison with a constant value (=, !=, >, >=, &lt;, &lt;=)
[`IsNullFilter`](/vgi/docs/python/api/vgi-table_filter_pushdown/#vgi.table_filter_pushdown.IsNullFilter): IS NULL check
[`IsNotNullFilter`](/vgi/docs/python/api/vgi-table_filter_pushdown/#vgi.table_filter_pushdown.IsNotNullFilter): IS NOT NULL check
[`InFilter`](/vgi/docs/python/api/vgi-table_filter_pushdown/#vgi.table_filter_pushdown.InFilter): Set membership (IN clause)
[`AndFilter`](/vgi/docs/python/api/vgi-table_filter_pushdown/#vgi.table_filter_pushdown.AndFilter): Conjunction of child filters
[`OrFilter`](/vgi/docs/python/api/vgi-table_filter_pushdown/#vgi.table_filter_pushdown.OrFilter): Disjunction of child filters
[`StructFilter`](/vgi/docs/python/api/vgi-table_filter_pushdown/#vgi.table_filter_pushdown.StructFilter): Nested struct field filter

<p class="api-section">Description</p>

Container for pushdown filters with evaluation and query helpers.

The top-level filters array represents a conjunction (AND). Each filter in
the array must be satisfied for a row to pass. Individual filters may
themselves be AND/OR compound filters for more complex expressions.

Provides:
- evaluate(batch) / apply(batch) - Apply filters using PyArrow compute
- get_column_bounds(name) - Extract numeric bounds for partition pruning
- get_column_constant(name) - Get equality constant for a column
- get_column_in_values(name) - Get IN list values
- get_column_filters(name) - Get all filters for a column
- to_sql() - Generate SQL WHERE clause
