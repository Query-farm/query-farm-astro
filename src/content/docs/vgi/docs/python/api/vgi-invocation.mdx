<p class="api-module-doc__label">Module overview</p>

Response types for the VGI protocol.

This module defines response dataclasses and the [`FunctionType`](/vgi/docs/python/api/vgi-catalog/#vgi.catalog.catalog_interface.FunctionType) enum:

- [`FunctionType`](/vgi/docs/python/api/vgi-catalog/#vgi.catalog.catalog_interface.FunctionType): Enum for scalar, table, and aggregate function types.
- [`BindResponse`](/vgi/docs/python/api/vgi-invocation/#vgi.invocation.BindResponse): Result of bind phase with output schema.
- [`BaseInitResponse`](/vgi/docs/python/api/vgi-invocation/#vgi.invocation.BaseInitResponse): Base class for init responses.
- [`GlobalInitResponse`](/vgi/docs/python/api/vgi-invocation/#vgi.invocation.GlobalInitResponse): Result of init phase with max_workers.

Request types (`BindRequest`, `InitRequest`) are in ``vgi.protocol``.

## <span class="api-icon api-icon--class"></span><span class="api-kind-tag api-kind-tag--class">class</span> `BindResponse`

<a class="api-source" href="https://github.com/Query-farm/vgi-python/blob/main/vgi/invocation.py#L51" target="_blank" rel="noopener">source</a>

<p class="api-bases">Bases: <code><a href="https://vgi-rpc-python.query.farm/" class="api-ext" target="_blank" rel="noopener">ArrowSerializableDataclass</a></code></p>

<p class="api-section">Description</p>

The result of calling bind() on a function.

The bind result is created by calling bind() and importantly contains
the function's output characteristics. It is serialized and sent to the
client before any data processing begins.

When ``lookup_secret_types`` is non-empty, this is a **secret scope
request** rather than a normal bind response. C++ resolves the requested
secrets and retries bind with ``resolved_secrets_provided=True``. The
developer never constructs scope requests directly — the framework
generates them when [`SecretsAccessor`](/vgi/docs/python/api/vgi-table_function/#vgi.table_function.SecretsAccessor) has pending lookups after
``on_bind()`` returns.
