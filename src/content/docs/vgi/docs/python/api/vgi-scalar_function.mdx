<p class="api-module-doc__label">Module overview</p>

Scalar functions: per-row transforms with single-column output.

Scalar functions are the simplest function type in VGI. They transform each
input row into exactly one output value, producing a single column of results.

Key characteristics:
- **1:1 row mapping**: Output has exactly the same number of rows as input
- **Single column output**: Output schema has exactly one column named "result"
- **No finish()**: Processing ends when the caller closes the input stream.

Common use cases:
- Mathematical operations: multiply, add, abs
- String transforms: upper, lower, concat, trim
- Type conversions: cast, parse
- Field extraction: get nested values, parse JSON fields

This module provides two base classes:

<dl class="api-deflist api-deflist--doc"><dt><a href="/vgi/docs/python/api/vgi-scalar_function/#vgi.scalar_function.ScalarFunction"><code>ScalarFunction</code></a> (recommended)</dt><dd>Declarative API using <a href="/vgi/docs/python/api/vgi-arguments/#vgi.arguments.Param"><code>Param</code></a>/<a href="/vgi/docs/python/api/vgi-arguments/#vgi.arguments.ConstParam"><code>ConstParam</code></a>/<a href="/vgi/docs/python/api/vgi-arguments/#vgi.arguments.Returns"><code>Returns</code></a> annotations on <code>compute()</code>. Also supports <a href="/vgi/docs/python/api/vgi-arguments/#vgi.arguments.Setting"><code>Setting</code></a>, <a href="/vgi/docs/python/api/vgi-arguments/#vgi.arguments.Secret"><code>Secret</code></a>, and <a href="/vgi/docs/python/api/vgi-arguments/#vgi.arguments.OutputLength"><code>OutputLength</code></a> annotations. Override <code>output_type()</code> only if the output type depends on input schema.</dd><dt><a href="/vgi/docs/python/api/vgi-scalar_function/#vgi.scalar_function.ScalarFunctionGenerator"><code>ScalarFunctionGenerator</code></a> (advanced)</dt><dd>Per-batch callback API for fine-grained control. Override <code>output_type()</code> and <code>process()</code>.</dd></dl>

## <span class="api-icon api-icon--class"></span><span class="api-kind-tag api-kind-tag--class">class</span> `ScalarFunction`

<p class="api-section">Description</p>

Base class for scalar functions (1:1 row mapping, single output column).

Scalar functions transform each input row to exactly one output value.
Use [`Param`](/vgi/docs/python/api/vgi-arguments/#vgi.arguments.Param)/[`ConstParam`](/vgi/docs/python/api/vgi-arguments/#vgi.arguments.ConstParam)/[`Returns`](/vgi/docs/python/api/vgi-arguments/#vgi.arguments.Returns) annotations on `compute()` to declare types.

**Type Validation**

Input and output types are validated at runtime:
- [`Param`](/vgi/docs/python/api/vgi-arguments/#vgi.arguments.Param) types are checked against actual array types
- [`Returns`](/vgi/docs/python/api/vgi-arguments/#vgi.arguments.Returns) type is checked against `compute()` result
- [`AnyArrow`](/vgi/docs/python/api/vgi-arguments/#vgi.arguments.AnyArrow) parameters skip validation
- [`TypeMismatchError`](/vgi/docs/python/api/vgi-scalar_function/#vgi.scalar_function.TypeMismatchError) is raised on mismatch

**Methods to Override**

<dl class="api-deflist api-deflist--doc"><dt><code>compute(self, ...) -&gt; pa.Array</code></dt><dd>Transform input arrays to output. Use <a href="/vgi/docs/python/api/vgi-arguments/#vgi.arguments.Param"><code>Param</code></a>/<a href="/vgi/docs/python/api/vgi-arguments/#vgi.arguments.ConstParam"><code>ConstParam</code></a> annotations.</dd></dl>
<dl class="api-deflist api-deflist--doc"><dt><code>output_type(params) -&gt; pa.DataType (classmethod)</code></dt><dd>Override when output type depends on input schema or arguments.</dd></dl>

<a id="vgi.scalar_function.ScalarFunctionGenerator"></a>
## <span class="api-icon api-icon--class"></span><span class="api-kind-tag api-kind-tag--class">class</span> `ScalarFunctionGenerator`

<a class="api-source" href="https://github.com/Query-farm/vgi-python/blob/main/vgi/scalar_function.py#L498" target="_blank" rel="noopener">source</a>

<p class="api-bases">Bases: <code>vgi.function.Function</code></p>

<p class="api-section">Description</p>

Per-batch callback base class for scalar functions.

This is the advanced API for scalar functions. For most use cases,
use [`ScalarFunction`](/vgi/docs/python/api/vgi-scalar_function/#vgi.scalar_function.ScalarFunction) instead, which provides a simpler `compute()` callback.

Scalar functions have these constraints:
- **1:1 row mapping**: Output row count must equal input row count
- **Single value output**: Produces one value per input row
- **No finalization**: Processing ends when input is exhausted

**Methods to Override**

<dl class="api-deflist api-deflist--doc"><dt><code>output_type(params) -&gt; pa.DataType</code></dt><dd>Return the Arrow type for the output value. Required.</dd></dl>
<dl class="api-deflist api-deflist--doc"><dt><code>process(...) -&gt; pa.RecordBatch</code></dt><dd>Process one input batch. Must return output with same row count. Required.</dd></dl>
<dl class="api-deflist api-deflist--doc"><dt><code>on_bind(params) -&gt; BindResult</code></dt><dd>Optional. Override to perform custom bind-time logic.</dd></dl>
<dl class="api-deflist api-deflist--doc"><dt><code>on_init(...) -&gt; GlobalInitResponse</code></dt><dd>Optional. Override to perform custom initialization.</dd></dl>

**Protocol Entry Points (called by worker, do not override)**

<dl class="api-deflist api-deflist--doc"><dt><code>bind(input) -&gt; BindResponse</code></dt><dd>Handles the bind API call</dd></dl>
<dl class="api-deflist api-deflist--doc"><dt><code>global_init(input) -&gt; GlobalInitResponse</code></dt><dd>Handles the global_init API call</dd></dl>
