Focused guides that each walk through one task end to end — exposing a catalog, persisting state,
serving over HTTP. Each assumes you've finished the [tutorial](/vgi/docs/python/tutorial/scalar/) and
can already write and run a basic worker.

Not sure which function shape you need? Start with
**[Function patterns](/vgi/docs/python/how-to/function-patterns/)** — a runnable worker for each of
the five shapes — then come back here for specific tasks.

## Guides

- **[Expose a catalog](/vgi/docs/python/how-to/catalogs/)** — surface schemas, functions, tables, and views to DuckDB
  via `ATTACH`.
- **[Publish global functions](/vgi/docs/python/how-to/global-functions/)** — make selected functions
  callable without naming the attached catalog.
- **[Add a custom COPY format](/vgi/docs/python/how-to/copy-formats/)** — implement `COPY … FROM` and
  `COPY … TO` for your own format or sink.
- **[Persist state across workers](/vgi/docs/python/how-to/state-storage/)** — shared, durable state for distributed
  aggregates.
- **[Serve over HTTP](/vgi/docs/python/how-to/serve-http/)** — run a worker as a network service.
- **[Use VGI from a Python app](/vgi/docs/python/how-to/python-app/)** — drive a worker from your own
  program with the `haybarn` engine, no CLI.
- **[Authentication](/vgi/docs/python/how-to/authentication/)** — gate an HTTP worker with bearer tokens or JWT/OAuth.
- **[Integrate with the optimizer](/vgi/docs/python/how-to/pushdown-and-statistics/)** — accept pushed-down filters and
  report column statistics.
- **[Cache results on the client](/vgi/docs/python/how-to/result-caching/)** — advertise TTLs and
  validators so repeat queries skip the worker entirely.

Each guide ends with a **Next steps** section that links onward to a concept page and the full
reference for that topic.
