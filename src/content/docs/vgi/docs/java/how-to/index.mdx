Focused guides that each walk through one task end to end. Each assumes you've finished the
[tutorial](/vgi/docs/java/tutorial/scalar/) and can already build and run a worker.

## Guides

- **[Function patterns](/vgi/docs/java/how-to/function-patterns/)** — scalar, table, table-in-out,
  aggregate and buffering, with a complete worker for each. *(Start here.)*
- **[Running a worker](/vgi/docs/java/how-to/running/)** — the JVM flags that are not optional, why
  `launch:` matters, the four transports, and the shared-memory path on JDK 25+.
- **[Expose a catalog](/vgi/docs/java/how-to/catalogs/)** — present the worker as a database:
  schemas, function-backed tables, views.
