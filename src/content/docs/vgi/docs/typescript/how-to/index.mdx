Focused guides that each walk through one task end to end. Each assumes you've finished the
[tutorial](/vgi/docs/typescript/tutorial/scalar/) and can already run a worker.

Not sure which function shape you need? Start with
**[Function patterns](/vgi/docs/typescript/how-to/function-patterns/)** — a runnable worker for each
of the five shapes — then come back here for specific tasks.

## Guides

- **[Function patterns](/vgi/docs/typescript/how-to/function-patterns/)** — scalar, table,
  table-in-out, aggregate and buffering, with a complete worker for each. *(Start here.)*
- **[Value representations](/vgi/docs/typescript/how-to/value-representations/)** — what a column's
  values actually are, why decimals are unscaled bigints, and the two read paths that don't agree.
  *(Read this before writing anything that touches a date or a decimal.)*
- **[Runtimes & entry points](/vgi/docs/typescript/how-to/runtimes/)** — Node, Bun, Cloudflare
  Workers and the browser, and which of the four subpath exports each one wants.
- **[Expose a catalog](/vgi/docs/typescript/how-to/catalogs/)** — present the worker as a database:
  schemas, function-backed tables, views.
- **[Serve over HTTP](/vgi/docs/typescript/how-to/serve-http/)** — `serveVgiWorker`, and the signing
  key every multi-instance deployment needs.
- **[Cache results on the client](/vgi/docs/typescript/how-to/result-caching/)** — advertise TTLs and
  validators so repeat queries skip the worker entirely.
- **[Call a worker from TypeScript](/vgi/docs/typescript/how-to/client/)** — `VgiClient`, for tests,
  tooling, and browser front-ends.
- **[Report errors well](/vgi/docs/typescript/how-to/errors/)** — the typed errors, the constraints
  you get for free, and the stack trace that reaches the SQL client.
