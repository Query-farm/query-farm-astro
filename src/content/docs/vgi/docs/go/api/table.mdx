<a id="TypedTableFunc"></a>
## <span class="api-icon api-icon--class"></span><span class="api-kind-tag api-kind-tag--class">interface</span> `TypedTableFunc`

<a class="api-source" href="https://github.com/Query-farm/vgi-go/blob/main/vgi/table_typed.go#L25" target="_blank" rel="noopener">source</a>

<Code lang="go" code={`type TypedTableFunc[S any] interface {
	// Name returns the function name used to invoke it in SQL.
	Name() string
	// Metadata returns descriptive metadata for the function.
	Metadata() FunctionMetadata
	// ArgumentSpecs returns the function's argument specifications.
	ArgumentSpecs() []ArgSpec
	// OnBind resolves the output schema and bind state from the bind parameters.
	OnBind(params *BindParams) (*BindResponse, error)
	// NewState creates a fresh, typed per-scan state value.
	NewState(params *ProcessParams) (*S, error)
	// Process generates output rows for one scan step, emitting them via out.
	Process(ctx context.Context, params *ProcessParams, state *S, out *vgirpc.OutputCollector) error
}`} />

<p class="api-section">Description</p>

TypedTableFunc is the recommended interface for table functions.
It provides compile-time type safety for state management, eliminating
the unsafe state.(*myType) assertions required by the lower-level
TableFunction interface.

Use the lower-level TableFunction interface only for advanced use cases
that need non-standard state patterns.

Implementations may also satisfy OnIniter (custom OnInit) and/or
CardinalityEstimator (cardinality estimation). These are detected
automatically by AsTableFunction.

</div>

<a id="GenerateBatch"></a>
## <span class="api-icon api-icon--function"></span><span class="api-kind-tag api-kind-tag--function">function</span> `GenerateBatch`

<a class="api-source" href="https://github.com/Query-farm/vgi-go/blob/main/vgi/table_generate.go#L61" target="_blank" rel="noopener">source</a>

<pre class="api-sig"><code>func GenerateBatch(bs *BatchState, out *vgirpc.OutputCollector, generateFn func(size int64) ([]arrow.Array, error)) error</code></pre>

GenerateBatch handles one batch of a batch-splitting table function.
Call this from Process — it handles the complete remaining-work pattern:

 1. If Remaining &lt;= 0, calls out.Finish() and returns
 2. Computes size = min(Remaining, BatchSize)
 3. Calls generateFn(size) to produce arrays
 4. Emits the arrays via out.EmitArrays
 5. Releases all returned arrays
 6. Updates Remaining and Index

VGI's Process is called once per batch by the framework. This function
processes exactly one batch per call — it does NOT loop.

The generateFn closure should capture bs.Index at the start to know the
current row offset before GenerateBatch advances it.

</div>

## <span class="api-icon api-icon--function"></span><span class="api-kind-tag api-kind-tag--function">function</span> `validateGobState`

<a class="api-source" href="https://github.com/Query-farm/vgi-go/blob/main/vgi/table_typed.go#L98" target="_blank" rel="noopener">source</a>

<pre class="api-sig"><code>func validateGobState[S any]()</code></pre>

validateGobState fails fast (at registration) when the per-scan state type S
cannot be gob-encoded for HTTP rehydration. gob otherwise surfaces these only
mid-query, on the first HTTP continuation, with a cryptic message. Two pitfalls
are caught by walking S's exported, gob-reachable fields:

  - a struct whose fields are all unexported (e.g. `struct{ done bool }`): gob
<Code lang="go" code={`encodes nothing and reports "type ... has no exported fields".`} />

  - an exported field of a kind gob cannot encode — an interface (the common
<Code lang="go" code={`case being an Arrow \`arrow.Record\`/\`arrow.Array\` stashed in state to emit
later), a chan, a func, or an unsafe.Pointer. The fix is to store plain
serializable Go values (slices, scalars) in state and rebuild the Arrow
batch in Process, mirroring the SDK's static_data.go example.
`} />

A truly empty `struct{}` is fine, and any type providing its own
gob.GobEncoder is exempt (at the top level or as a nested field). Mirrors
vgi-python enforcing serializable state at class-definition time.
