<Code lang="go" code={`type Filter interface {
	// ColumnName returns the name of the column this filter applies to.
	ColumnName() string
	// ColumnIndex returns the index of the column in the output schema.

<a id="PushdownFilters.GetColumnValues"></a>
#### <span class="api-icon api-icon--method"></span><span class="api-kind-tag api-kind-tag--method">method</span> `GetColumnValues`

<a class="api-source" href="https://github.com/Query-farm/vgi-go/blob/main/vgi/filter_helpers.go#L123" target="_blank" rel="noopener">source</a>

<pre class="api-sig"><code>func (pf *PushdownFilters) GetColumnValues(name string) arrow.Array</code></pre>

GetColumnValues returns discrete values a column could have based on
equality or IN filters. For EQ, wraps the value in a 1-element array.
Returns nil if no discrete values can be determined.

Descends one level into AndFilter children (via collectColumnFilters),
consistent with GetColumnBounds: DuckDB pushes `col = v` / `col IN (...)`
conjoined with derived range bounds as a single AndFilter (e.g. a semi-join
emits `col IN (...) AND col >= min AND col <= max`). Without the descent the
discrete-value fast path silently misses those and pruning callers fall back
to scanning every partition.

An OrFilter resolves to the UNION of its branches, but only when every branch
pins this column to discrete values; if any branch is a range/IS NULL or
constrains a different column the set is not enumerable and we return nil.

EqualOrInValues returns the values from a single `column = X` ConstantFilter,
a single `column IN (...)` InFilter, or an AND-conjunction of such filters

the repeated scalar-to-Go-value conversion code that workers otherwise
write to support filter pushdown on string / integer key columns.
