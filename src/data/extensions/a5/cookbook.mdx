## Spatial Data Aggregation

Group point data spatially to understand distributions:

```sql
-- Analyze restaurant density by A5 cells
SELECT a5_lonlat_to_cell(longitude, latitude, 15) AS cell_id,
       COUNT(*) AS restaurant_count
FROM restaurants
GROUP BY cell_id
ORDER BY restaurant_count DESC;
```


## Visualizing a Cell as GeoJSON

Combine [`a5_cell_to_boundary`](#a5_cell_to_boundary) with the spatial extension to produce a GeoJSON polygon for any cell:

```sql
SELECT
    ST_AsGeoJSON(
        ST_MakePolygon(
            ST_MakeLine(
                list_transform(
                    a5_cell_to_boundary(
                        a5_lonlat_to_cell(-3.7037, 40.41677, 10)
                    ),
                    x -> ST_Point(x[1], x[2])
                )
            )
        )
    ) AS geojson;
```

## Neighborhood Queries

All cells within `k` edge-steps (edge adjacency):

```sql
SELECT a5_grid_disk(a5_lonlat_to_cell(-74.0060, 40.7128, 15), 1) AS neighbors;
```

All cells within a radius (in meters) of a center cell:

```sql
SELECT a5_spherical_cap(a5_lonlat_to_cell(-74.0060, 40.7128, 15), 5000.0) AS nearby_cells;
```

## Compaction

[`a5_compact`](#a5_compact) replaces complete groups of sibling cells with their parent cell:

```sql
SELECT a5_compact([
    324259173170675712,
    396316767208603648,
    468374361246531584,
    540431955284459520
]::ubigint[]) AS result;
```

<QueryResult columns={["result"]} rows={[["[360287970189639680]"]]} />

[`a5_uncompact`](#a5_uncompact) is the inverse — expanding a set of cells to a target resolution.
