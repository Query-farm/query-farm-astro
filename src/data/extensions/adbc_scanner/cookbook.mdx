The examples below use the runtime-command API described in Technical Details. Install the SQLite ADBC driver and its manifest before running examples with `driver: 'sqlite'`; alternatively use its shared-library path.

## Create and query a SQLite table

```sql
SET VARIABLE conn = (SELECT adbc_connect({'driver': 'sqlite', 'uri': ':memory:'}));
CALL adbc_execute(getvariable('conn')::BIGINT, 'CREATE TABLE users(id INTEGER, name TEXT)');
CALL adbc_execute(getvariable('conn')::BIGINT, 'INSERT INTO users VALUES (1, ''Alice''), (2, ''Bob'')');

-- SQLite requires explicit result columns for arbitrary SQL.
SELECT * FROM adbc_scan(
  getvariable('conn')::BIGINT,
  'SELECT id, name FROM users WHERE id = ?',
  params := row(1),
  columns := {'id': 'BIGINT', 'name': 'VARCHAR'}
);

-- Scanning a named table can obtain its schema from table metadata.
SELECT * FROM adbc_scan_table(getvariable('conn')::BIGINT, 'users');
SELECT * FROM adbc_schema(getvariable('conn')::BIGINT, 'users');
CALL adbc_disconnect(getvariable('conn')::BIGINT);
```

## Bulk insert from a DuckDB query

```sql
SET VARIABLE conn = (SELECT adbc_connect({'driver': 'sqlite', 'uri': ':memory:'}));
SELECT * FROM adbc_insert(
  getvariable('conn')::BIGINT,
  'users',
  (SELECT * FROM (VALUES (1::BIGINT, 'Alice'), (2::BIGINT, 'Bob')) AS source(id, name)),
  mode := 'create'
);
SELECT * FROM adbc_scan_table(getvariable('conn')::BIGINT, 'users');
CALL adbc_disconnect(getvariable('conn')::BIGINT);
```

## Commit and roll back

```sql
SET VARIABLE conn = (SELECT adbc_connect({'driver': 'sqlite', 'uri': ':memory:'}));
CALL adbc_execute(getvariable('conn')::BIGINT, 'CREATE TABLE users(id INTEGER, name TEXT)');
CALL adbc_set_autocommit(getvariable('conn')::BIGINT, false);
CALL adbc_execute(getvariable('conn')::BIGINT, 'INSERT INTO users VALUES (1, ''Alice'')');
CALL adbc_commit(getvariable('conn')::BIGINT);
CALL adbc_execute(getvariable('conn')::BIGINT, 'INSERT INTO users VALUES (2, ''Bob'')');
CALL adbc_rollback(getvariable('conn')::BIGINT);
CALL adbc_set_autocommit(getvariable('conn')::BIGINT, true);
SELECT * FROM adbc_scan_table(getvariable('conn')::BIGINT, 'users'); -- Alice only
CALL adbc_disconnect(getvariable('conn')::BIGINT);
```

## Attach an existing SQLite file for analytics

Replace the path with a SQLite file containing your application tables. Each `:memory:` connection has its own database; use a file when independent connections need to share data.

{/* check: skip requires an existing SQLite application database */}
```sql
ATTACH '/data/app.db' AS local_app (TYPE adbc, READ_ONLY, driver 'sqlite');
SHOW TABLES FROM local_app.main;
SELECT * FROM local_app.main.users;
DETACH local_app;
```
