## Use cases

- **Quick data exploration** — visualize distributions and trends directly in your terminal.
- **Dashboard cells** — drop a sparkline into a status table without a charting library.
- **Monitoring & alerting** — visual indicators for system metrics and KPIs.
- **Data quality checks** — spot outliers and patterns at a glance.
- **CLI analytics** — beautiful output for scripts and one-liners.
- **Documentation** — embed live charts in READMEs and report exports.
- **Embedded analytics** — lightweight visualizations in apps without heavy frontend dependencies.

## Bars

Inline bars with [`tp_bar`](#tp_bar) — value as a fraction of `min..max`.

```sql
-- Simple progress
SELECT tp_bar(0.5);

-- Out-of-100 with explicit width
SELECT tp_bar(75, min := 0, max := 100, width := 20);
```

### Threshold-based coloring

Conditional colors based on the value — green/yellow/red zones for SLAs and dashboards:

```sql
SELECT tp_bar(85, min := 0, max := 100,
  thresholds := [
    {'threshold': 90, 'color': 'red'},
    {'threshold': 70, 'color': 'yellow'},
    {'threshold':  0, 'color': 'green'}
  ]) AS sla;
```

### Random walk dashboard

```sql
SELECT round(n, 4) AS value,
       tp_bar(n,
              width := 14,
              shape := 'circle',
              off_color := 'black',
              filled := true,
              thresholds := [
                (0.8, 'red'), (0.7, 'orange'), (0.6, 'yellow'), (0.0, 'green')
              ]) AS bar
FROM (SELECT random() AS n FROM generate_series(10));
```

### Custom characters

`on` and `off` are SQL reserved words — quote them:

```sql
SELECT tp_bar(0.7, "on" := '█', "off" := '░', width := 15);
```

## Sparklines

[`tp_sparkline`](#tp_sparkline) — compact one-line trends.

### Three modes

```sql
-- Absolute mode (default) — height ∝ value
SELECT tp_sparkline([45.2, 47.1, 46.8, 49.3, 52.1, 48.7]);

-- Delta mode — direction of change between consecutive points
SELECT tp_sparkline([100, 105, 102, 108, 95], mode := 'delta');

-- Trend mode — direction with magnitude
SELECT tp_sparkline([100, 110, 105, 125, 90], mode := 'trend', theme := 'intensity');
```

### Themes

Each mode has a vocabulary of themes. A few favorites:

```sql
-- Faces emoji for delta
SELECT tp_sparkline([72, 75, 75, 78, 71], mode := 'delta', theme := 'faces');

-- Slopes for trend
SELECT tp_sparkline([10, 12, 11, 15, 8], mode := 'trend', theme := 'slopes');

-- ASCII for terminal compatibility
SELECT tp_sparkline([25, 45, 78, 92, 67, 34], theme := 'ascii_basic', width := 15);
```

## Density plots

[`tp_density`](#tp_density) — compact distribution view for an array.

```sql
-- Default shaded style
SELECT tp_density([1, 2, 3, 4, 5, 4, 3, 2, 1]);

-- Wide plot in 'height' style
SELECT tp_density([1, 2, 3, 2, 1], width := 30, style := 'height');

-- ASCII style
SELECT tp_density([1, 5, 3, 8, 2], style := 'ascii');

-- Dot style for subtle visualization
SELECT tp_density([1, 5, 3, 8, 2], style := 'dots');

-- Rainbow emoji
SELECT tp_density([1, 5, 3, 8, 2], style := 'rainbow_circle');
```

### Built-in styles

| Style | Characters |
|---|---|
| `shaded` (default) | ` ░▒▓█` |
| `ascii` | `` .:+#@`` |
| `dots` | ` .•●` |
| `height` | ` ▁▂▃▄▅▆▇█` |
| `circles` | `⚫⚪🟡🟠🔴` |
| `rainbow_circle` | `⚫🟤🟣🔵🟢🟡🟠🔴⚪` |

## QR codes

[`tp_qr`](#tp_qr) — encode a string as Unicode-block QR.

```sql
-- Default monochrome
SELECT tp_qr('Hello, World!');

-- High error correction (more redundancy, slightly bigger code)
SELECT tp_qr('https://query.farm', ecc := 'high');

-- Custom colors
SELECT tp_qr('https://query.farm', ecc := 'high', "on" := '🟡', "off" := '⚫');
```

`.mode ascii` in the DuckDB CLI gives the cleanest rendering of QR output.

## Tips

1. **Pick widths to match your output** — width 20–30 for dashboards, 10–15 for compact reports.
2. **Use thresholds for status** — perfect for SLA / health / risk indicators.
3. **Combine with numbers, don't replace them** — text plots complement raw values.
4. **ASCII for portability, emoji for impact** — emoji needs a Unicode-capable terminal/font.
5. **Sparklines shine in tables** — one cell per row, instant per-entity trend visibility.
